YTGrab

Grab the video. Or just the part you want.

A Windows app for downloading from YouTube, TikTok, X, Instagram and about 1,800 other sites, as MP4 or MP3, with a start and end you pick.

Download for Windows (.zip)

Needs Python (3.13 works). Unzip it anywhere, then follow the setup below once.

One-time setup

  1. Install ffmpeg, which handles clipping, MP3 and frame previews. Open Command Prompt and run:
    winget install Gyan.FFmpeg
  2. Double-click build.bat in the unzipped folder and wait. It installs everything and makes dist\YTGrab.exe.
  3. Open the dist folder, right-click YTGrab.exe and choose Pin to taskbar. From then on, it's one click.

Skipping the exe? Run this once in the folder, then double-click run ytgrab.bat:

pip install -r requirements.txt

What it does

Clips, not whole videosDrag the start and end sliders or type times like 1:05:30. Only that section downloads.
Frame previewSee roughly where you're cutting before you download.
Send to your phoneScan a QR code on the same Wi-Fi and the video lands on your phone.
Signed-in videosPick the browser you're logged into for age-restricted or members-only videos.

If downloads stop working

The site changed something. Update the download engine:

pip install -U yt-dlp

Streaming services with DRM, like Netflix and Disney+, can't be downloaded.
